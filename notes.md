# Introduction to GitHub - What I Learned

## What is GitHub?
GitHub is an online platform that lets you store and manage your code using Git. 
It makes it easier to track changes, collaborate with others, and keep a history 
of your project at every stage.

## Key Concepts I Understood

**Repositories** are basically project folders that store all your files and their history.

**Branches** let you work on changes separately without messing up the main project, 
which is useful when you're testing something new.

**Commits** are like checkpoints — you save your progress with a message describing 
what you changed.

**Pull Requests** are how you propose merging your changes into the main branch, 
and they allow others to review your work first.

**Issues** help track bugs or tasks that need to be done in a project.
